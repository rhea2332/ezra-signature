# The Ezra Clinic – email signature

Hosted with GitHub Pages. Open the Pages link, check the preview, click **Copy signature**, and paste into Gmail or Outlook.

## Images still to add to `images/`
- `logo.gif` – the animated logo
- `facebook.png`, `instagram.png`, `youtube.png` – 40×40px icons (they display at 20px)

## Editing
- Contact details: edit the `D = { ... }` block near the bottom of `index.html`.
- Banner: replace `images/banner.png` with a new file of the same name (1200px wide). Signatures already installed update automatically.
